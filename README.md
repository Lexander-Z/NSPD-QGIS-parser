# NSPD-QGIS-parser

Выгрузка атрибутов и векторной геометрии объектов НСПД (nspd.gov.ru) по
клику по карте в QGIS. По клику отправляется WMS-запрос GetFeatureInfo,
ответ разбирается, и объекты с атрибутами дописываются в файл GeoPackage.

Поддерживаемые слои НСПД:

| Слой | Код слоя НСПД | Слой в GeoPackage | Имя файла по умолчанию |
|---|---|---|---|
| Кадастр: земельные участки ЕГРН | 36048 | `NSPD_Kadastr` | `NSPD_Kadastr.gpkg` |
| ЗОУИТ объектов культурного наследия | 37577 | `ZOUIT_OKN` | `ZOUIT_OKN.gpkg` |
| ЗОУИТ объектов энергетики, связи, транспорта | 37578 | `ZOUIT_Energetika_svaz_transport` | `ZOUIT_Energetika_svaz_transport.gpkg` |
| ЗОУИТ охраняемых объектов и безопасности | 37579 | `ZOUIT_ohranyaemyh_ob_i_bezopasnosti` | `ZOUIT_ohranyaemyh_ob_i_bezopasnosti.gpkg` |
| ЗОУИТ природных территорий | 37580 | `ZOUIT_prirodnyh_territorii` | `ZOUIT_prirodnyh_territorii.gpkg` |
| Иные ЗОУИТ | 37581 | `Inye_ZOUIT` | `Inye_ZOUIT.gpkg` |

## ВНИМАНИЕ: сначала установите сертификаты Минцифры

**Без корневых сертификатов Минцифры НСПД не отвечает, и выгрузка не
работает.** Это самая частая причина отказов. Есть два способа.

**В систему** (подходит и для скрипта, и для плагина, и для браузера):

1. Скачайте и установите сертификаты: https://www.gosuslugi.ru/crt
2. **Перезагрузите компьютер.**

**Только в QGIS, через плагин** (без прав администратора, система не меняется):

1. Установите плагин (см. «Способ 2» ниже) и откройте его панель.
2. В блоке «Связь с НСПД» нажмите «Сертификаты...», затем «Скачать и
   установить в QGIS».

Плагин скачивает сертификаты с официального адреса gu-st.ru (на него ведут
ссылки со страницы gosuslugi.ru/crt), сверяет их отпечатки SHA-256 и
кладёт их только в хранилище сертификатов QGIS (Настройки - Параметры -
Аутентификация - Управление сертификатами). Учтите: после этого QGIS
доверяет всем сайтам с сертификатами этого центра, а не только НСПД.
Удалить их можно в том же окне кнопкой «Удалить из QGIS». Почему сделано
именно так, описано в [docs/ANALYSIS.md](docs/ANALYSIS.md), раздел 6.

Если сертификатов нет, в консоли (или в журнале панели плагина) появится
сообщение вида:

```
NSPD [ошибка]: «Кадастр: земельные участки ЕГРН»: запрос к nspd.gov.ru не выполнен: SSL handshake failed
Похоже, QGIS не доверяет сертификату nspd.gov.ru: нужны корневые сертификаты Минцифры. Установите их с https://www.gosuslugi.ru/crt и перезагрузите компьютер. Если стоит плагин NSPD Parser, их можно установить только в QGIS: кнопка «Сертификаты...» в его панели.
```

## Что есть в репозитории

| Путь | Что это |
|---|---|
| `nspd_parser.py` | Скрипт для консоли Python в QGIS. Один на все слои: слой выбирается при запуске. |
| `nspd_core.py` | Общая логика запроса и записи. Нужна и скрипту, и плагину. Должна лежать рядом с `nspd_parser.py`. |
| `plugin/` | Плагин QGIS с панелью: можно выгружать несколько слоёв сразу, есть кнопки «Начать» и «Остановить». |
| `legacy/` | Старые скрипты `NSPD v6.2 *.py`. Не развиваются, см. [раздел ниже](#старые-скрипты-legacy). |
| `docs/ANALYSIS.md` | Разбор старых скриптов: что было сломано и что исправлено. |

Есть два способа работы: скрипт в консоли (ничего устанавливать не нужно)
и плагин (удобнее, если выгружаете часто или сразу несколько слоёв).

## Способ 1. Скрипт в консоли Python

#### 0. Установите сертификаты Минцифры (см. выше) и перезагрузите компьютер

#### 1. Скачайте репозиторий

На странице репозитория: **Code - Download ZIP**, распакуйте в любую папку.
Файлы `nspd_parser.py` и `nspd_core.py` должны лежать в одной папке.

> Раньше на этом шаге нужно было создать папку `C:\1`. Теперь это не нужно:
> файл для сохранения выбирается при запуске.

#### 9. Выберите файл GeoPackage

Появится окно сохранения файла. Имя предлагается по выбранному слою,
папка запоминается с прошлого раза. Скриншота этого окна пока нет.

- Если файла нет, он будет создан.
- Если файл уже есть, он **не перезаписывается**. Если в нём уже есть

  и ЗОУИТ, запуская скрипт для каждого слоя.

#### Настройки скрипта

В начале `nspd_parser.py` есть две настройки:

- `FEATURE_COUNT` (по умолчанию 20): сколько объектов просить у НСПД за
  один клик. Если пришло ровно столько, в консоли будет предупреждение, что
  выдача могла быть обрезана. Тогда увеличьте значение или кликните точнее.
- `TIMEOUT_S` (по умолчанию 30): сколько секунд ждать ответа НСПД. Пока
  идёт запрос, QGIS не реагирует; по истечении времени запрос отменяется.

## Способ 2. Плагин QGIS

### Сборка архива

Нужен Python 3, QGIS для сборки не нужен. В корне репозитория выполните:

```
python plugin/build_zip.py
```

Получится файл `dist/nspd_parser_plugin.zip`. Скрипт сразу проверяет
архив и печатает его содержимое. В конце должна быть строка
`Проверка архива: пройдена`.

### Установка

1. Модули - Управление и установка модулей - **Установить из ZIP**.
2. Выберите `dist/nspd_parser_plugin.zip`, нажмите «Установить модуль».
3. На панели инструментов появится кнопка «Выгрузка объектов НСПД», а в
   меню веб-модулей (Web; в русском интерфейсе обычно «Интернет») — пункт «НСПД».

Скриншотов плагина пока нет.

### Работа

Нажмите кнопку «Выгрузка объектов НСПД». Справа откроется панель «Выгрузка
НСПД», блоки в ней идут в порядке работы.

1. **Связь с НСПД.** Вверху написано, доверяет ли QGIS сертификатам
   Минцифры. Если нет, нажмите «Сертификаты...» и установите их в QGIS (см.
   начало этого файла). Кнопка «Проверить связь» делает пробный запрос к НСПД
   и пишет результат.
2. **Какие слои выгружать.** Отметьте нужные слои: можно несколько сразу,
   тогда каждый клик опрашивает все отмеченные. Галочка «Показывать
   отмеченные слои НСПД на карте» при запуске добавит их WMS-слои в группу
   «НСПД» (если их ещё нет), чтобы было видно, куда кликать. Кнопка «Добавить
   отмеченные слои на карту» делает то же самое без запуска выгрузки.
3. **Куда сохранять.** Файл GeoPackage уже подставлен (`NSPD.gpkg` в
   последней папке, папке проекта или домашней папке), поменять его можно
   кнопкой «Обзор...». Каждый слой НСПД пишется в свой слой внутри файла.
   Если файл уже есть, объекты дописываются.
4. **Дополнительно** (свёрнуто): «Объектов за клик» и «Таймаут запроса».
5. Нажмите **«Начать выгрузку»** и кликайте по карте. Курсор становится
   перекрестием, на время запроса — часами. Добавленные объекты на секунду
   подсвечиваются. Под кнопками видно, сколько объектов добавил последний
   клик и сколько всего за сеанс. Подробности — в журнале внизу панели и в
   журнале сообщений QGIS (вкладка «НСПД»).
6. Нажмите **«Остановить»**, когда закончите. Выгрузка также
   останавливается, если выбрать другой инструмент карты или закрыть панель.

Перед запуском плагин делает один пробный запрос к НСПД. Если QGIS не
доверяет сертификатам, сначала появится предложение установить их. Если НСПД
не отвечает, выгрузка не начнётся, а под кнопками будет написано почему.

Выбранные слои, путь и настройки запоминаются до следующего запуска.

### Для разработки

Вместо установки из ZIP можно подключить папку `plugin/nspd_parser_plugin`
символической ссылкой в каталог плагинов профиля QGIS
(`.../QGIS3/profiles/default/python/plugins/`). В этом случае `nspd_core.py`
берётся из корня репозитория, и правки видны после перезагрузки плагина.

## Совместимость

Код рассчитан на QGIS 3.16 и новее и на QGIS 4 (Qt6). Сторонние библиотеки
не нужны: `shapely` больше не используется. Проверка в живом QGIS 4 пока не
проводилась. Что менялось ради Qt6 и почему, описано в
[docs/ANALYSIS.md](docs/ANALYSIS.md).

## Старые скрипты (legacy)

Шесть скриптов `NSPD v6.2 *.py` (по одному на слой) перенесены без изменений
в папку `legacy/` для тех, кто к ним привык или ссылается на них. **Это
старые версии: они не развиваются и не исправляются.** Их известные
проблемы описаны в [docs/ANALYSIS.md](docs/ANALYSIS.md). Главные из них:

- нужен модуль `shapely`, которого во многих сборках QGIS нет;
- файл всегда пишется в `C:/1` и при каждом запуске перезаписывается целиком;
- скрипт «ЗОУИТ природных территорий» из-за опечатки в коде слоя
  (`37580/wms`) не может вернуть ни одного объекта;
- в QGIS 4 старые скрипты работать не будут.

Если всё же пользуетесь ими: перед запуском создайте папку `C:\1`. В
редакторе консоли откройте скрипт с названием нужного слоя. Результат
появится в `C:/1/<имя слоя>.gpkg`. После выгрузки пересохраните файл в
другое место, а из папки `C:\1` удалите. Если скрипт сообщил об ошибке
сохранения, удалите слой из папки `C:\1`:
